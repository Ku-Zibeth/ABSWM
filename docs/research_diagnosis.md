# ABSWM 2.0 第一阶段诊断

## 结论

在 60 组未见过的 Burckhardt 参数、两种初速度和三个训练种子上，World Model + PI 到 2 m/s 的平均制动距离为 **78.50 m**，NLS + PI 为 **73.10 m**。按路面配对的平均差为 **+5.40 m**，路面簇 bootstrap 95% 区间为 **[+3.98, +6.94] m**。各基线均完成制动。

闭环差距主要出现在**最优滑移率参考生成**。经过裁剪和限速的 World 参考仍偏离真实峰值 19.73 个百分点，NLS 为 0.16 个百分点。同期 PI 对各自参考的跟踪 RMSE 分别为 2.19 和 2.14 个百分点。给同一 PI 换上延迟至相同冷启动时刻的真实峰值，平均距离降到 73.10 m。这个干预定位的是当前闭环的瓶颈。世界模型产生的未来轨迹在该闭环中没有参与选扭矩。

历史表征本身有用。用同一个网络打乱 $z$ 后，100 ms 轮速 RMSE 从 5.87 升至 21.29 rad/s。用训练路面拟合的线性探针，在测试路面仅用 $z$ 预测峰值的 MAE 为 1.94 个百分点，原轮胎头全局取峰为 23.32 个百分点。两者使用同一组测试窗口。这组结果优先支持检查**物理监督、轮胎曲线解码及参考生成**，随后再评估递归结构的增益。

本次复核校验了路面清单、完整参数组合的哈希与拆分、原训练和验证窗口位置、原开放环测试窗口位置及覆盖区间。对现有入口，改变未来状态和 $T_{b,t}$ 不会改变 $t$ 的编码历史。真实 $T_{b,t}$ 从下一状态起生效。训练和推理均未发现测试路面参数、峰值或轮胎力进入可部署估计器。Oracle、模拟对象、评价标签、探针测试评分和数值积分对照使用各自明示的真值。

公平性有三项实质差异。

- NLS 和 World 接收同一组可用传感量。NLS 明确利用无噪声车速差分、正确的 Burckhardt 函数族和典型起点。World 的车速差分也是因果可用的，但需要 GRU 和轮胎头自行解码。Direct 有训练路面的真峰值监督，World 只在真实轨迹的当前滑移及未来状态上受监督。当前实验检验同一函数族的未见参数组合。
- 开放环和双曲线实验中的 NLS 每个窗口重置。闭环 NLS 保留上一组参数，等效地利用部分早期激励。闭环估计器产生各自的轨迹，参考误差随各方法遭遇的观测分布变化。第 5 节利用相同历史和延迟 Oracle 分别检验这两点。Fixed 的开放环动力学使用公开湿地曲线，闭环仍使用固定 0.12。NLS 重置且拟合失败时同样以湿地曲线预测动力学，同时报告固定参考峰值。
- 原始开放环窗口按日志扭矩作条件预测。日志的释放动作可能由当时的真实滑移反馈触发。候选扭矩绝不能从还未观测的未来响应中取得。原分支实验在同一初态上预先定义候选扭矩，能检验这一边界。观测区间为最近历史的滑移率最小值至最大值，区间内部也可能缺少密集样本。原闭环报告按代码包含全部距离。当前 1,440 条全部完成。新增配对脚本单独记数和排除未完成配对。

## 3. 低滑移下的峰值可辨识性

曲线 A 是测试路面 `8fc6c969ed1a9cd3`，峰值 **12.975%**。曲线 B 是 `7d6195bd8288c99a`，峰值 **18.560%**。两曲线在 0–2%、0–5%、0–10%、0–20% 内的最大 $\lvert\Delta\mu\rvert$ 分别为 **0.00877、0.08921、0.21680、0.29760**。在 0–2% 内，这相当于最多 30.1 N 的四分之一车轮胎力差。

每条曲线使用相同的两种初速度和四个预设扭矩斜率。对每个滑移上限截取首次越过前的观测，只交给估计器最后 50 行。估计器看不到越界样本、当前待执行扭矩、路面标识、曲线参数和真峰值。64 个前缀均达到各自上限附近，所用历史的平均最大滑移为 1.97%、4.92%、9.85%、19.56%。窗口有时丢弃前面已观测的低滑移段。由于两条曲线的响应不同，越界时刻和对应的扭矩不同，表中的斜率、起始速度与上限配对对齐。

| 观测上限 | NLS 峰值 A / B | Direct 峰值 A / B | World 峰值 A / B | NLS 全曲线 $\mu$ RMSE A / B | World 全曲线 $\mu$ RMSE A / B |
|---:|---:|---:|---:|---:|---:|
| 2% | 26.28 / 43.16% | 14.34 / 14.39% | 25.68 / 25.81% | 0.150 / 0.214 | 0.271 / 0.319 |
| 5% | 18.61 / 29.18% | 14.55 / 15.35% | 28.72 / 30.75% | 0.080 / 0.122 | 0.308 / 0.276 |
| 10% | 13.26 / 18.94% | 13.48 / 15.62% | 29.36 / 34.28% | 0.017 / 0.021 | 0.213 / 0.256 |
| 20% | 12.99 / 18.58% | 12.71 / 15.51% | 32.40 / 37.79% | 0.0023 / 0.0024 | 0.136 / 0.186 |

- **2% 时，低范围拟合准确也不能证明峰值准确。** NLS 的历史区间内 $\mu$ RMSE 约 0.0006，两个峰值都明显偏高。即使无传感器噪声，车速差分给出的区间平均 $\mu$ 与中点真实 $\mu$ 的 RMSE 仍约 0.00066/0.00067。以真实参数仅在评价端计算的 $\partial\mu/\partial\log\theta$ 中位条件数，A/B 约为 27,582 / 50,478。到 20% 降为 146 / 315。低滑移展开的首项主要约束 $c_1c_2-c_3$。曲线并非完全重合，在模型形式正确且精度足够的条件下仍有辨识信息。这次实验看到的是有限历史下的**实际弱可辨识性**。
- **峰前推断依赖函数族与已见曲率。** 10% 仍低于两条曲线的真实峰值，正确函数族的 NLS 已将 A/B 峰值误差降至平均 0.29 / 0.38 个百分点。Direct 在 2% 时的平均峰值差只有 0.055 个百分点，远小于真值的 5.59 个百分点差。World 即使观测达 20%，两个峰值的平均绝对误差仍约 19 个百分点，弱激励无法单独解释这个结果。
- **训练种子间波动不能代替预测区间。** World 在 2% 时三个种子的峰值范围平均宽度约为 6.8 个百分点，但 A 和 B 的各 8 次试验均没有真值落入该范围。四种上限的 64 次也均未覆盖。Direct 在 2% 时范围宽度小于 0.45 个百分点，两个真峰值均未覆盖。现有三个估计器都只提供点估计，当前实验不能给出概率校准结论。逐实例的最小值、最大值及真值覆盖保存在 `pair_seed_spread.csv`。
- **加入局部非参数对照。** PCHIP 采用与 NLS 相同的历史中点样本、并包含 $(0,0)$，最高样本以上按末值常量延拓。2% 时 A/B 的全曲线 RMSE 为 0.221 / 0.449。20% 时峰值误差降至约 0.12 / 0.16 个百分点，但全曲线 RMSE 仍为 0.141 / 0.203。该方法适合核对局部拟合与已经经历的峰值，远端延拓由常量假设决定。

原实验的 60 路面前缀结果提供了更广的对照。在第一次越过各自真峰值 90% 之前，用 50 行历史得到的峰值 MAE，NLS 为 0.28 个百分点，Direct 为 1.80，World 为 17.73。真峰值在该实验中用于事后切分。

干预固定当前状态和未来动作，只替换 $z$，随机置换保留测试 $z$ 的边际样本集合且供体来自不同路面。力曲线和动力学明显依赖 $z$ 与历史的正确配对，但全局取峰几乎不受置换影响。常量 $z$ 使峰值指标看似改善时，曲线及动力学同时退化。结合有峰值标签的线性探针，这表明当前最优滑移率指标的瓶颈与读取 $z$ 的方式有关。截短实验衡量现有权重对可用历史的敏感性。

## 5. 估计、PI 和闭环距离

轨迹内跟踪、参考与力利用率按控制区间时长加权，再对试验平均。力利用率为瞬时实际 $F_x/F_{x,\max}$。原始峰值 MAE 由原评估按更新后保持的估计在每控制步计算。World 冷启动后约 62.9% 的时长原始峰值超出参考限幅。参考限速造成的额外参考追随差为 1.74 个百分点。扭矩达到幅值上限的时长均为零，World/NLS 的扭矩变化率触限占比分别为 2.25% / 2.35%。全部原始对照均无大于 0.8 的高滑移时段。雪地贡献最大，World 和 NLS 在雪地的平均距离为 164.44 m 和 151.61 m。

针对两个初速各抽一条 World 轨迹，以存档的在线估计值回放 PI 和被控对象，重现状态、扭矩、参考及距离。然后在全部 120 个路面与初速组合运行 Oracle 延迟干预，前 250 ms 使用 0.12，之后在相同更新节拍供应真实峰值，继续使用原来的参考限幅、限速、PI 和扭矩执行器。延迟 Oracle 比原 Oracle 多 0.424 m，World 比延迟 Oracle 多 5.400 m。去除参考估计误差后，同一闭环在距离上达到 NLS 水平。这个差值包含参考改变后轨迹和后续观测的变化。

同一 Fixed 闭环历史上，独立比较 NLS 重置与保留参数两种用法。0.25 s 刚开始估计时两者峰值 MAE 同为 12.83 个百分点。0.50 s 分别为 0.67 和 0.45，1.00 s 为 2.05 和 0.36。2.00 s 在仍继续制动的 87 个样本中为 4.29 和 0.48，此时重置版本全部触发低激励回退。第 1 次更新以后保留参数的 NLS 一直有估计，说明持续在线记忆在滑移稳定后仍有辨识价值。该对照同时保留了热启动差异与回退差异。

## 6. 优先事项与下一阶段验收

1. **先让轮胎头在制动工况可用。** 4,096 个训练窗中只有 108 个（2.6%）的当前滑移距真峰值在 ±2 个百分点内。1,200 个窗的历史最大滑移已达 99%，另有 1,361 个低于 5%。训练同时覆盖峰前和近锁止，峰区当前力的直接监督相对稀少。建议在相同路面拆分和 PI 上，比较峰区加权、物理形状约束、联合的当前力与峰值监督。验证集同时保留峰值、区间内外曲线、一步和反事实多步状态误差，选模兼顾估计质量和动力学精度。
2. **把可辨识性与模型能力分开评分。** 保留 A/B 四个覆盖级别，扩展到多条近似低滑移曲线及另一轮胎函数族。以训练路面和验证路面开发模型与校准方法，在冻结的测试路面按激励范围报告覆盖率和区间宽度。将正确函数族的 NLS、不同函数族下的 NLS、非参数拟合并列，以判断结构先验何时有益。附着估计分布和候选动作的力误差更直接服务于后续控制。 [Berntorp, Bayesian Tire-Friction Learning by Gaussian-Process State-Space Models](https://www.merl.com/publications/TR2019-051)
3. **冻结本阶段基线，再检验递归记忆。** 首先比较同计算量下的固定窗 GRU、跨窗记忆及物理监督消融，检查它们在激励消退后能否保持合理的恒定路面判断。评估已知外部扭矩分支下的多步误差，随后再比较确定性递归状态和 RSSM 的先验与后验。后续用 Oracle-MPC 和固定 PI 作控制对照，单独量化预测参与决策的收益。 [Hafner et al., Learning Latent Dynamics for Planning from Pixels](https://proceedings.mlr.press/v97/hafner19a.html)
