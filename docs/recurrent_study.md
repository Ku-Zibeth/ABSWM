# ABSWM 2.0 递归潜在状态与动作条件预测

**E4 A 是 ABSWM 2.0 的正式基础模型。** 采用完整附着曲线损失联合训练历史编码器与物理约束轮胎解码器的三个种子权重（11、22、33）。模型登记绑定原基础配置、Decoder 训练配置和 E4 A 选择结果。加载器核对训练输入、测试档案、权重与对应实验清单，递归实验独立写入新目录。 [模型登记](../configs/abswm_2.json) · [解码研究](decoder_study.md)

## 模型与时序

| 方法 | 吸收真实观测 | 未来候选扭矩预测 |
|---|---|---|
| E4 A | 每次重算最近 50 行的 GRU，保持原权重 | 通过固定潜在状态和已知车辆动力学预测 |
| E4 A streaming | 从轨迹起点保持 GRU 隐状态，保持原权重 | 固定潜在状态 |
| 递归观测 | 从 E4 A 初始化，训练持续更新的观察器，冻结轮胎解码器 | 固定潜在状态 |
| 递归转移 | 同样初始化和训练持续更新的观察器，另学习确定性潜在转移 | 每步根据候选扭矩和预测车速、轮速更新想象潜在状态 |

在线观测始终为 $[v_t,\omega_t,\lambda_t,T_{b,t-1}]$。观察器保存 GRU 隐状态和前一观测行，后者用于计算与 E4 A 一致的因果差分特征。每条真实轨迹在起点用同样的重复首行规则初始化，测试中只初始化一次。训练通过最多 150 行因果观测反向传播，测试按完整前缀持续更新。

预测从时刻 $t$ 的真实后验复制状态。一步 $t\rightarrow t+1$ 中，原 1 ms 投影 Euler 在当前潜在状态和指定扭矩下推进已知车辆动力学。递归转移版随后用预测状态、已知扭矩和前一想象潜在状态更新潜在向量，供下个控制周期使用。转移零初始化，每周期各分量残差幅值上限为 0.015。不同动作分支共享起始后验，各自推进，预测完成后真实后验仍可继续接收观测。预测所需输入只有历史、车辆常量和指定扭矩。

## 训练和验收协议

- 沿用原训练、验证、测试路面的完整参数组合拆分。用固定种子从原 4,096 个训练窗抽取 768 个训练起点，沿用全部 512 个验证窗和 512 个测试窗。递归候选从对应 E4 A 种子开始继续训练 5 轮。按三个种子的平均验证分数选验收候选，验证分数同时评估车辆状态、力与动作响应差。
- 每批保留一个“保持扭矩”分支，加上随机选取的日志动作、释放、增加或脉冲分支。起点相同。增加分支相对保持的请求高 600 Nm，脉冲在后半程恢复保持请求。所有候选动作经过原幅值和变化率限制。反事实真值由 RK4 仿真生成，真实参数只生成标签。训练损失由未来车速和轮速、未来附着、相对保持的状态响应差及想象潜在漂移组成。
- 验收从同一后验预测 5、25、50、75、100 ms 的车速、轮速、滑移率与轮胎纵向力。除原日志动作外，验收还比较释放、增加和脉冲各自相对保持扭矩的响应差。候选扭矩在预测前给定。另用 2%、5%、15% 的首次越界前缀检查低激励情形。
- 验收门槛预先登记。相对正式 E4 A，100 ms 的轮速动作响应差 RMSE 至少降低 5%，且同一时域日志动作的车速、轮速、滑移率和制动力 RMSE 任一项劣化不超过 5%。同时报告种子标准差、动作响应方向正确率、按路面聚类的配对误差和各候选动作分项。方向正确率只计入真实轮速响应差幅值至少 1 rad/s 的情形。
- 反馈试验在 50 ms 揭示真实观测，继续预测到 100 ms。“只修正车辆状态”保留原潜在状态或已推进的想象潜在状态。“同时修正潜在状态”额外吸收截至 50 ms 的真实历史。三个对照均使用同一段后续已知扭矩。该试验单独衡量观察器修正的收益。

## 复现

已有 [解码研究](decoder_study.md) 输出时，在项目根目录运行下面两条命令。

~~~powershell
uv run pytest -q
uv run python scripts/recurrent_study.py
~~~

首次运行需要先完成原基础实验和 E4 A 训练。配置位于 configs/abswm_2.json 与 configs/recurrent_study.json，脚本支持指定基础运行、正式权重和独立输出路径。默认结果目录为 outputs/recurrent_study。

36 项自动化测试通过。新增覆盖批量与逐次观测更新的一致性、因果前缀、零初始化转移、预测对真实后验的隔离、扭矩约束、标签隔离和验收门槛。固定窗 E4 A 的 100 ms 轮速 RMSE 与上一阶段结果相符。

## 首轮结果

**验证集选出的递归转移模型通过预登记的动作条件验收。** 综合验证分数为 0.2748，递归观测版为 0.2758。在 60 组未见路面的 512 个测试窗口上，100 ms 的轮速动作响应差 RMSE 从 5.362 降至 5.038 rad/s，降低 **6.05%**。日志动作下，车速、轮速和滑移率误差分别下降 2.12%、1.69% 和 2.58%，轮胎力误差上升 2.51%，符合单项最多劣化 5% 的限制。

| 方法 | 100 ms 车速 RMSE m/s | 轮速 RMSE rad/s | 滑移率 RMSE 百分点 | 轮胎力 RMSE N | 轮速动作响应差 RMSE rad/s |
|---|---:|---:|---:|---:|---:|
| E4 A | 0.0591 | 4.518 | 9.50 | 364.1 | 5.362 ± 0.371 |
| E4 A streaming | 0.0585 | 4.477 | 9.44 | 361.5 | 5.408 ± 0.376 |
| 递归观测 | 0.0568 | 4.366 | 9.24 | 368.0 | 5.103 ± 0.526 |
| 递归转移 | 0.0578 | 4.441 | 9.25 | 373.3 | 5.038 ± 0.479 |

表中先计算每个种子的窗口 RMSE，再取三种子均值。动作列的 ± 为样本标准差。只把 E4 A 的 GRU 从固定窗改为持续更新，动作响应差的误差略增 0.85%。递归观测通过训练把动作响应差误差降低 4.84%，接近预设门槛，日志动作下的轮速误差最低。递归转移在同一起点上的释放、增加、脉冲三项响应差 RMSE 分别为 2.51、6.80、4.86 rad/s，E4 A 对应为 2.75、7.27、5.08。忽略动作差异、始终预测保持扭矩响应时，该指标为 20.01 rad/s。主要改进在响应幅值，显著动作的轮速方向在四种方法中已有约 99.6% 以上正确率。

将逐窗的响应差绝对误差按路面聚类后，递归转移减去 E4 A 的平均差为 −0.080 rad/s，描述性 95% 区间 [−0.198, +0.045]。该量和验收采用的整体 RMSE 有不同权重。**本轮达到了点估计门槛，路面间增益仍有不确定性。** 递归观测与递归转移的差也没有在这一统计量上稳定分开。

| 测试前缀 | 窗口 | E4 A 轮速响应差 RMSE rad/s | 递归观测 | 递归转移 |
|---|---:|---:|---:|---:|
| 2% | 120 | 11.79 | 11.06 | 10.55 |
| 5% | 120 | 6.13 | 6.44 | 6.03 |
| 15% | 120 | 3.84 | 3.48 | 3.45 |

2% 前缀仍是最难工况。增加扭矩分支的递归转移轮速响应差 RMSE 为 13.80 rad/s，表明早期激励不足仍限制动作比较。不同前缀确实有不同改善幅度。

### 50 ms 反馈与计算量

| 方法 | 100 ms 无反馈轮速 RMSE rad/s | 50 ms 仅用新车辆状态 | 50 ms 同时更新潜在状态 |
|---|---:|---:|---:|
| E4 A | 4.518 | 3.082 | 1.604 |
| E4 A streaming | 4.477 | 3.069 | 1.598 |
| 递归观测 | 4.366 | 3.048 | 1.383 |
| 递归转移 | 4.441 | 3.069 | 1.391 |

在准确的真实观测重新可用时，更新潜在状态给两种递归模型带来的改善都大于只重置车速、轮速。递归转移的 p95 单行更新为 0.181 ms，E4 A 的 50 行重编码为 1.304 ms。递归转移的 20 步单候选预测 p95 为 22.27 ms，E4 A 为 20.97 ms。每个种子在 CPU 上预热后测量 28 次，表述为三种子 p95 均值。递归观测和基线各有 10,305 个参数，递归转移有 12,513 个。六个训练权重的轮胎 Decoder 均与登记的 E4 A 逐张量一致。

递归转移可作为下一轮动作预测研究的首选候选，正式基线仍是 E4 A。后续对照应保留递归观测版，以检验多步转移在弱激励、换轮胎函数及路面变化下是否仍有收益。本轮证据来自无测量噪声、单次仿真内附着恒定的四分之一车。
