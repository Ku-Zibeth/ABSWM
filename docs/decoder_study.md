# ABSWM 2.0 潜在状态解码研究

冻结原 GRU 后，完整曲线监督将附着 RMSE 从 **0.3465 降至 0.1917**。加入低滑移率特征和门控后，E3 进一步降至 **0.1777**。解冻 Encoder 的 E4 A 在同学习率冻结对照上还有增益，达到 **0.1662**。这证明原历史表征支持更有效的完整曲线解码。在极低滑移、个别路面族及尾部函数改变时，外推仍依赖训练分布。

## 实验设计

本阶段比较冻结和联合训练条件下的峰值预测、完整附着曲线重建和动力学预测。基础运行是第一阶段独立复跑的 300/60/60 组路面。所有主结果沿用其 4,096 个训练窗、512 个验证窗和 512 个测试窗，以及 11、22、33 三个训练种子。每个测试窗用最近 50 行因果观测和同一组未来作用扭矩进行评价。完整参数组合的路面集合互斥，窗口位置逐项核对原运行。

冻结和联合训练沿用原历史编码器接口。部署侧曲线只接收历史推断的潜在状态 $z$ 和查询滑移率 $\lambda$。训练和验证可以用其自身路面的完整曲线、最佳滑移率、当前附着以及未来车辆状态计算损失。参数在离线生成标签后丢弃。输入保持已知物理尺度归一化，线性探针只用训练潜在向量拟合中心及标准差。测试曲线和峰值在后处理评分时使用，测试历史和预测动作独立传给推理函数。

| 方法 | 初始化与训练 |
|---|---|
| Current、World、Direct、NLS | 复用第一阶段已有权重或实现。NLS 在每个窗口重新估计，失败时曲线沿用公开湿地先验、峰值沿用固定参考。 |
| Linear Probe | 沿用第一阶段的标准化岭回归设定，惩罚系数 0.01。输入为冻结的 World $z$。 |
| E2 | 冻结同种子 World Encoder，用两层 64 单元 SiLU MLP 和峰值标签训练 35 轮。输出范围为原参考区间 $[0.02,0.35]$。 |
| E3 原轮胎头 | 冻结同一 Encoder、保持原轮胎头形式与初始化，用全曲线训练 22 轮。这个对照主要改变监督目标。 |
| E3 | 同样冻结 Encoder。用 $(\lambda,\lambda/(\lambda+0.04),z)$ 查询 MLP，再用 $2\tanh[(\lambda/(\lambda+0.04))\,\mathrm{softplus}(\mathrm{MLP})]$ 得到附着。解析门控保证零滑移附着为零、非负且上界为 2。 |
| E3 继续、E3 匹配 | 从 E3 的同种子最优权重继续训练 12 轮，Encoder 始终冻结。E3 继续沿用冻结轮胎头学习率 0.002，E3 匹配采用与 E4 相同的轮胎头学习率 0.0007。 |
| E4 A–D | 从同一个 E3 权重开始，解冻 World Encoder，Decoder 与 Encoder 学习率分别为 0.0007 和 0.0002。每个配置继续训练 12 轮。 |
| E4 D 峰区加权 | 与 D 匹配初始化、训练步数和各损失系数。仅把均匀曲线 MSE 改为按样本归一的高斯权重，真峰值处权重为 4，尺度为 0.025。 |

两个轮胎头都允许非单峰曲线，均使用已知四分之一车动力学和原 1 ms 投影 Euler 积分器。曲线损失在 81 个固定的均匀滑移率点查询同一个 $z$ 并取 MSE。状态损失用原先的 $[1,10]$ 缩放因子和 20 步自由滚动，点损失用原先的当前附着系数和 1.5 缩放。峰值损失用温度 0.02 的预测附着 softmax 对各网格点离真峰值的归一化平方距离求期望。训练时真实峰值只参与误差及样本加权，预测时在 1,001 个 $[0,1]$ 网格点上取最大值，并同时报告峰值附着。报告中的 E4 峰值来自曲线。

训练中分别记录各损失和验证峰值 MAE。E2 按验证峰值 MAE 选权重，其余曲线模型统一按「曲线 RMSE + 0.5 × 峰值 MAE + 0.5 × 归一化状态 RMSE」选权重。E4 的损失系数按顺序在同一个预先采样的 1,024 训练窗上用种子 11 各试训 4 轮。每次用原 512 验证窗比较两个候选系数。正式三种子实验共用入选系数。峰值对照和曲线及滚动对照分别评分。

## 评价协议

- **原分布窗口。** RMSE 先按窗口或窗口内网格点合并，再对训练种子取均值。覆盖区间由每个窗口的观测滑移率最小值与最大值确定。另按路面族、历史最大滑移率和 5、25、50、75、100 ms 预测端点分别报告。Linear Probe、Direct 和 E2 只具备峰值预测接口，对其余指标留空。
- **A/B 低滑移。** 沿用第一阶段指定的双曲线、两种初始速度、四种共同扭矩斜率，在第一次越过 2%、5%、10%、20% 前截取最后 50 行。散布区间表示三种子极差。A/B 汇总先对每个种子的配对工况取均值。
- **未见扭矩分支。** 在每条测试路面刚要超过 5% 滑移前固定历史，分别释放、保持或增加扭矩。所有候选动作在预测前给定，并尊重原幅值和变化率约束。RK4 按各候选序列生成真值。
- **轮胎函数分布压力测试。** 保持测试路面的峰值和至少前 25% 滑移的 Burckhardt 曲线，之后平滑升高或降低尾部。用同一施加扭矩生成原尾部、降低尾部和升高尾部的历史，在 20% 和 65% 截止处评分。20% 的三个尾部条件具有完全相同的历史。65% 的历史能看到部分尾部差异。该测试衡量有控制的函数失配，仍属于合成四分之一车。
- **统计和效率。** 稳定性用三个训练种子的样本标准差。配对差值先对每条路面的窗口和种子平均，再用 2,000 次路面簇 bootstrap 给出描述性区间。机器计时用 CPU 单窗口预热后 100 次调用，峰值时延包含编码和网格搜索或 NLS 拟合，滚动时延包含编码和 20 步预测。

### E2 冻结峰值头

同一个预训练 $z$ 上，MLP 将线性探针的平均峰值误差从 1.94 降至 1.81 个百分点，接近独立训练的 Direct（1.74）。按路面配对的差为 −0.16 个百分点，95% 区间 [−0.24, −0.07]。E2 三个种子分别为 1.71、1.79、1.94 个百分点。E2 在干地、湿地、雪地分别为 2.26、1.64、1.57 个百分点，线性探针为 2.58、1.53、1.73。按历史最大滑移率分箱，E2 在低于 2%、2–5%、5–10%、10–20%、20–50%、50–100% 的 MAE 分别为 3.04、2.93、1.44、1.14、1.42、1.26 个百分点。冻结表征已能读出较准的峰值，换复杂头取得的额外收益较小，低滑移偏差仍存在。

### E3 曲线解码与 E4 损失消融

原轮胎头换用完整曲线监督后，曲线 RMSE 降约 45%，轮速端点误差也下降。此对照冻结 Encoder 并保留头的结构与各种子初始化，训练轮数、学习率和选模目标随任务调整。E3 的低滑移特征和门控进一步降低曲线及峰值误差，100 ms 轮速 RMSE 则从 4.93 小幅升至 5.10 rad/s。峰位和滚动质量应分别检查。

验证试训选择了状态 0.60（候选 0.20、0.60）、点损失 0.50（0.20、0.50）、峰值 0.002（0.002、0.008），曲线权重固定为 1。A 只用曲线，B 增加状态，C 再增加点损失，D 再增加峰值项。A、B、C、D、D 加权的三种子综合验证分数分别为 0.2723、0.2966、0.2948、0.2927、0.2963。在本次搜索预算内，A 的综合验证分数最低，也是统一测试上曲线误差、曲线峰值误差和 100 ms 状态误差最小的联合配置。B 加状态项后，曲线和 100 ms 状态的平均测试误差均回升。C 在 B 上加入点监督后，当前附着 RMSE 从 0.0762 降至 0.0671，但峰值 MAE 升至 7.56 个百分点。D 将这个峰值误差拉回 6.62，轮速端点和观测上界外曲线略退化。峰区加权把峰值 MAE 从 6.62 小幅降到 6.49，曲线 RMSE、峰值附着、100 ms 滚动误差及种子间峰值波动同时变大。现有结果只检验了指定高斯权重，原 4,096 个训练窗中峰附近的观测较少，仍需通过改善激励覆盖验证数据稀缺的影响。

当前制动力 RMSE 随曲线解码改善。World、E3 和 E4 A 分别约为 610、283、223 N，NLS 为 47 N。

### 联合训练的潜在表征

E4 A 与 E3 匹配对照从同种子、同一权重开始，使用相同 Decoder 学习率、继续训练轮数、样本次序和选模标准。解冻后，三个种子的曲线 RMSE 都下降。总体从 0.1741 降至 0.1662，轮速端点 RMSE 从 4.92 降至 4.52 rad/s。先按路面聚合逐窗误差后，曲线 RMSE 差为 −0.0089，95% 区间 [−0.0137, −0.0040]。轮速端点绝对误差差为 −0.274 rad/s，区间 [−0.396, −0.167]。这些配对差值与上表先合并全部窗口再算 RMSE 的量略有区别。

### 外推和训练分布

## 研究判断

1. **原 Encoder 已能提供实用的峰值和曲线信息。** E2 接近 Direct，保持原曲线头结构的 E3 对照也大幅降低了曲线误差。有限激励下的潜在信息有上限。
2. **主要改进来自完整曲线监督和 Decoder。** 同一冻结表征上即可获得大部分收益。轮胎头参数化还能改善峰位和低滑移曲线，但数据的激励和函数族覆盖决定可支持的外推，单靠 Decoder 无法补足。
3. **冻结 Encoder 可以显著恢复原分布的完整曲线。** E3 的 RMSE 较 World 降低约 49%，同时改善多步误差。相同表征上的专用峰值头仍比曲线直接取峰更准确。
4. **联合训练有可测的增量。** 匹配冻结对照和相同线性探针共同显示 E4 A 改善了曲线解码和物理信息可读性。增加指定的状态、点和峰值组合没有进一步提高综合表现。
5. **未见滑移区的预测可靠性取决于已见激励。** 极低滑移时两条曲线的峰位无法稳健分开。增加扭矩的分支有改进，但误差仍明显。
6. **模型仍依赖 Burckhardt 训练分布。** 尾部压力测试表明同一初始历史支持多条曲线。即使看到部分失配尾部，E4 A 仍把降低后的尾部往训练分布拉回。
7. **建议以 E4 A 作为下一阶段递归世界模型的初始化。** 同时保留冻结 E3 作为表征对照、E2 作为独立峰值基线。递归实验以多步候选动作表现、弱激励及独立轮胎函数测试作为验收指标。

## 复现

在项目根目录用 PowerShell 7 运行。已有第一阶段基础输出时，可直接运行后两条命令。

~~~powershell
uv sync --extra dev
uv run abswm run --config configs/full.json --output outputs/diagnosis_reproduced
uv run pytest -q
uv run python scripts/decoder_study.py --base outputs/diagnosis_reproduced --config configs/decoder_study.json --output outputs/decoder_study
~~~

训练、评价和原基线日志分别保存在新输出目录及其子目录。各轮训练数据和权重的来源由基础运行的 manifest 与新实验的 experiment.json 记录。evaluation.json 保存测试档案和评价源码哈希，训练配置、源代码或基础模型指纹变化时使用新的输出目录。

在现有 Windows CPU 环境中，原基础实验九个模型训练总计约 932 s。新实验含试训及冻结对照共约 799 s，完成评价、计时和出图用 147 s。E2、E3、E4 A 的单种子训练用时均值约 2.1、9.0、11.1 s。E4 B、C、D 和峰区加权版需反向传播 20 步车辆状态，单种子平均约 53–56 s。每个模型的实测记录见训练清单及 CSV。
